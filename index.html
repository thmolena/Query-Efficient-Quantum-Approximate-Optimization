Query-Efficient Quantum Approximate Optimization via Graph-Conditioned Trust Regions

Molena Huynh · North Carolina State University

When can local refinement improve transferred QAOA parameters within a measurement budget? This study connects trust-region radius, model bias, shot noise, and decision power through controlled experiments and predictions on fresh graphs.

01 / Evidence

What the study shows

A useful starting point can leave improvements that are difficult to propose and measure.

The revised analysis separates radius-dependent sampling from stopping after unresolved evidence. A conditional bias–variance prediction is tested against independent finite-shot observations on eight fresh graphs. These simulator-informed diagnostics explain model accuracy; the recorded quality–cost comparisons do not establish a competitive measurement advantage.

In the canonical benchmark, simple descriptor transfer gives strong initial solutions. Under the tested finite-shot acceptance rule, undisplaced donor-initialized trust-region policies accept no refinement steps. The results therefore distinguish initialization benefits from optimization improvements.

02 / Further checks

Depth, targets & solver sensitivity

Two separately seeded panels add 448 held-out runs on 16 test graphs at depths 2 and 3, with a separate validation split. The bank uses 8/10-vertex graphs, validation uses 12, and tests use 12/14. Validation selects a common model-shot count and initial radius for the isotropic and shaped variance-sensitive rules before testing.

1 follow-up test graph is isomorphic to a canonical test graph; 15 are structurally distinct from the canonical test set. There is also 1 bank-to-bank overlap between studies. All follow-up bank, validation, and test graphs are mutually nonisomorphic within that study. The manuscript also reports sensitivity after excluding the test overlap.

Intervals use 10,000 graph resamples within each bank and seed 5713, conditional on the two fixed reference banks; they are descriptive and unadjusted. Two banks do not estimate uncertainty over a population of reference banks. Tuning consumes 8,170,240 optimization shots plus 1,048,576 validation shots. Exact simulation, best-found reference construction, and solver preprocessing are separate classical costs.

All four tuning candidates tie on validation scores at each depth; the declared candidate order selects 256 model shots and radius 0.1. This tie provides no evidence of tuning superiority. The variance-sensitive rules refine a few held-out outputs, while SPSA and COBYLA achieve lower mean deficits.

The solver audit checks all 384 canonical graph pairs. Longer entropic runs at regularization 0.05 change 1 of 24 evaluable target donors; 3 pairwise candidates remain unconverged and 0 fail feasibility. An independent multistart conditional-gradient solver changes 21 of 24 evaluable donors. Feasibility or a small first-order gap does not certify a globally optimal graph comparison.

03 / Approach

From graph to search

  1. Transfer a reference. Compare graph descriptors, structural transport scores, or exact local-neighborhood distributions against a separate reference bank.
  2. Construct the region. Align periodic QAOA angles and regularize the region shape at controlled volume and conditioning.
  3. Fit and test a step. Use a QR-based local linear model and fresh paired samples for finite-horizon acceptance decisions.
  4. Account for every query. Preserve model evaluations, rejected trials, unresolved decisions, validation shots, and preprocessing costs.

The manuscript supplies a graph-local transfer bound, a conditional model-error decomposition, a finite-sample error bound, and a finite-horizon acceptance guarantee. Exact simulator inputs to the predictive diagnostics are distinguished from the measurements available to the optimizer.

04 / Reproduction

Inspect. Run. Verify.

The folder includes exact graphs, reference parameters, complete run records, source snapshots, independent numerical checks, and figure-generation code. No Git history is needed. Use Python 3.13; full PDF verification also needs Tectonic or pdfLaTeX/BibTeX and Poppler.

python3.13 -m venv code/.venv
source code/.venv/bin/activate
python -m pip install -r code/requirements-lock.txt
python -m pip install --no-deps -e code
python code/scripts/check_release.py
python code/scripts/run_smoke.py --config code/configs/smoke.json

Regenerate the saved analyses or run a new study with the commands in the README. Strict trajectory replay uses the documented OpenBLAS environment. New executions preserve the supplied evidence and write their own records, including interrupted runs. A full study takes several minutes on the recorded machine; exact state-vector simulation grows exponentially with vertex count. Numerical backends can change optimizer trajectories, as documented with the saved environment.
