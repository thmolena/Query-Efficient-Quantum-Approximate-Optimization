# Attribution and rights

The [manuscript bibliography](../../submission/refs.bib) gives the scientific references. Each entry's `annote` field records its role, supporting passage or implementation evidence, and verification scope; these annotations do not appear in the compiled reference list. The folder checker compares citations with the source and compiled bibliography and rejects missing or unused entries, duplicate identifiers, and wildcard inclusion. These mechanical checks complement source review; they do not establish scientific support by themselves.

| Implementation | Scientific attribution and scope |
| --- | --- |
| [qaoa.py](../src/gcqaoa/qaoa.py) | Farhi, Goldstone, and Gutmann's QAOA construction (`farhi2014`); independent statevector implementation for unweighted MaxCut. |
| `qaoa.normalized_shortest_path_matrix`, `search.structural_score` | Structural GW comparison (`memoli2011`, `peyre2016`) and entropy-scaled transport (`cuturi2013`), inspired by SCOT (`demetci2022`). Couplings provide graph scores, not angle maps or certified global optima. |
| `search.design_points`, `search.fit_model` | Conventional QR least squares (`golub2013`), column pivoting (`businger1965`), and interpolation geometry (`conn2008`). Ordinary pivoted QR does not imply strong rank-revealing guarantees. |
| [search.py](../src/gcqaoa/search.py) | Finite-horizon acceptance uses Hoeffding (`hoeffding1963`) or empirical Bernstein (`maurer2009`) bounds. Comparators use SPSA (`spall1992`) and COBYLA (`powell1994`) through SciPy's PRIMA implementation (`zhang2023prima`). |
| [experiment.py](../src/gcqaoa/experiment.py), [followup.py](../src/gcqaoa/followup.py) | Graph generators follow `gilbert1959`, `steger1999`, `barabasi1999`, and `watts1998` through NetworkX (`hagberg2008`), with additional connectivity and isomorphism filters. Multistart BFGS (`nocedal2006`, `scipy2020`) supplies best-found, locally optimized references. |
| [artifacts.py](../src/gcqaoa/artifacts.py), [report.py](../src/gcqaoa/report.py) | Custom NumPy percentile bootstrap (`efron1993`, `harris2020`) with graph-level resampling; follow-up intervals stratify within fixed banks. Figures use Matplotlib (`hunter2007`). |
| [transport_audit.py](../src/gcqaoa/transport_audit.py) | A separate conditional-gradient comparison reports a numerical first-order gap (`lacostejulien2016`), without claiming exact stationarity or global optimality. |

The Introduction distinguishes these implemented components from related transfer, model-based optimization, shot-allocation, and stochastic trust-region methods. Those cited methods are not all experimental baselines, and their convergence theorems are not attributed to this finite-budget policy. Time-uniform confidence sequences (`howard2021`) are a possible extension, not an implemented acceptance rule.

The [Cartan quantum synthesizer repository](https://github.com/kemperlab/cartan-quantum-synthesizer) inspired the compact research presentation. This reconstruction includes no source code or visual assets from that project or SCOT, and does not vendor external libraries or research datasets. Synthetic graphs are generated by the recorded experiment.
